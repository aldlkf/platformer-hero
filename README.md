# Platformer Hero

2D-платформер на Unity (2022.3.5f1). Пройдите 3 уровня, собирайте вишни и избегайте ловушек.

## Управление
| Действие | Клавиши |
|---|---|
| Движение | A / D или стрелки |
| Прыжок | Space (чем дольше держите, тем выше прыжок) |
| Пауза | Esc |

## Возможности
- 3 уровня + стартовый и финальный экраны
- Ловушки: пила, шипы, огонь, Rock Head, Spiked Ball
- Движущиеся платформы (WaypointFollower, StickyPlatform)
- Сбор вишен со сквозным счётом между уровнями
- Смерть от ловушек и от падения за карту, перезапуск уровня
- Coyote time и jump buffer для отзывчивого прыжка
- Плавная камера, меню паузы

## Структура скриптов (`Assets/Scripts`)
| Скрипт | Назначение |
|---|---|
| PlayerMovement | движение, прыжок, анимации |
| PlayerLife | смерть, перезапуск уровня |
| ItemCollector | подбор вишен, счётчик на экране |
| GameSession | счёт между уровнями |
| CameraController | следование камеры за игроком |
| Finish | завершение уровня, переход дальше |
| WaypointFollower | движение платформ и ловушек по точкам |
| StickyPlatform | игрок «прилипает» к движущейся платформе |
| Rotate | вращение пил |
| StartMenu / EndMenu / PauseMenu | меню |

## Запуск
1. Установите Unity 2022.3.5f1 (или новее 2022.3 LTS).
2. Откройте папку проекта через Unity Hub.
3. Откройте сцену `Assets/Scenes/Start Screen.unity` и нажмите Play.
